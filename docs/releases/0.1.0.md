# Web 0.1.0

Glance opens a small browser in your screen corner with `⌃⌥Space`. Search Google, YouTube or DuckDuckGo, paste a link, or choose **Open in Glance** from a link's context menu. Pin the page or open it in Web. Links from private tabs stay private when opened as full tabs. Closing Glance releases its temporary session.

Web now targets macOS 26.5, with a continuous Liquid Glass window surface and a vector globe icon. The View menu lets you choose sidebar, top or hidden tabs, show the address bar, or enter Focus Mode. The start page shows saved pages and recent visits using cached icons. Private tabs hide recents.

Select a passage and choose **Copy Quote** to copy it with the page link. The command palette searches tabs, commands and the web. Pin tabs, duplicate a page, remove duplicates, or opt in to session restore. Find in Page works from the keyboard; address fields share one URL parser.

The assistant is read-only. Cloud page sharing requires a fresh opt-in. Provider defaults now come from the current official catalogs, and a failed request no longer triggers a chain of model guesses.

This release tightens stored-password origin checks, certificate exceptions, private storage and download filenames. Warning and offline views show the current problem and available actions. Settings that did not change behavior have been removed.

The unsigned Release build and all 65 tests passed. Local MLX generation and Stop are verified; cloud completions need more testing. This is a development preview. Public distribution requires a Developer ID signature and notarization. See [validation](../validation.md), the [security review](../security-audit.md) and [browser gap](../product-direction.md).
