# Web 0.1.2

A new tab catches the light. Two reflections follow the search field’s edge and fade. Typing is ready immediately. Turn it off in Appearance; Reduce Motion and Low Power Mode also keep it still.

The assistant has a small glass globe while it works, with **Thinking** and **Writing** states. It stops moving when the window is inactive. Model downloads keep their progress bar.

Fresh walkthroughs show Local AI, Glance, Focus Mode and Copy Quote in the current app, against a macOS wallpaper. The original Web banner stays.

The light and globe use original SwiftUI drawing, inspired by [Libraries.dev](https://libraries.dev/) and the precise state changes in [Transitions.dev](https://transitions.dev/). No animation package was added.

This is a development preview. See the [validation record](../validation.md) for tested behavior and remaining limits.
