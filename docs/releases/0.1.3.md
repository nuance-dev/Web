# Web 0.1.3

[Download for Mac](https://github.com/nuance-dev/Web/releases/tag/v0.1.3). Apple Silicon, macOS 26.5+. Signed with Developer ID and notarized by Apple.

A page-reading timeout could crash Web when its result arrived late. That race is fixed. Reading now happens on request, without background scans, scrolling or persistent page observers. Form fields, drafts and hidden content stay out of the extracted text.

**Custom API** connects an OpenAI-compatible server. Enter its base URL, model and key in Settings. Keys and page-sharing permission belong to that endpoint. Local servers can use HTTP on loopback; remote connections require HTTPS.

**Glance** has a single native glass edge. Copy Quote has been removed; the page keeps its standard Copy action.

Source builds now use ad-hoc signing, with no Apple Developer account required. The [release tools](../releasing.md) verify sandbox entitlements, notarization and local account paths before packaging. Third-party license notices ship with the app.

The new walkthroughs use three different sites, with shorter cuts and a question that depends on the article being read. The original Web banner stays.

Apple Silicon. macOS 26.5 or later. This is a development preview; see the [validation record](../validation.md) for checks and limits.
