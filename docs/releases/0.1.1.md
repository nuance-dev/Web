# Web 0.1.1

The toolbar and tab stack now float above the window background. The page has its own rounded edge, with narrow gaps between surfaces. The tab stack ends after the last tab; commands sit separately below it.

Turn on **Match page color** in Appearance to blend the frame with the current page. The setting starts off. Hidden navigation opens in its own space above the page, so it cannot cover website controls.

Background tabs start loading when opened. New-window links open in front; Command-click and middle-click open behind the current page. Switching tabs keeps the selected tab in view. Hover a sidebar tab to close it, or press `⌘S` to move tabs between the sidebar and top.

Find now takes keyboard focus reliably. Press `⇧⌘B` for Focus Mode or `⇧⌘H` to show or hide the address bar. Focus also hides the assistant, restoring it when you return.

Use `⇧⌘S` to hide and restore tabs in their previous position. Help → Commands and Shortcuts opens a searchable list of actions and their keys.

Assistant replies now render headings, lists, quotes, tables and code. Code blocks have a Copy button. Links open in Web, and Markdown images do not make network requests.

The assistant has one visible open or close control at a time. Its composer shows the attached page as a small card with its title and cached icon. Clicking the card opens the sharing controls. A compact summary action replaces the welcome text.

Web no longer replaces website timers. This removes one cause of interrupted page scripts, but Google sign-in still needs verification.

This is a development preview. See the [validation record](../validation.md) for tested behavior and remaining limits.
