# Concrete browser interactions

| Status | Interaction |
| --- | --- |
| Built | Press the configured shortcut to open Glance in the screen corner. Type a URL or search, press Return, and browse there. Escape closes it. |
| Built | Right-click a web link and choose **Open in Glance**. It opens in the corner without adding a tab or navigating the source page. |
| Built | Choose **Open in Web** from Glance to continue in a full tab. Links opened from private tabs stay private when expanded. |
| Built | Press **⌘K**, type part of a tab title or command, and press Return. |
| Next, not built | Drop a link onto the Glance input to open it. This can use the same navigation and privacy rules as the context-menu action. |
| Next, not built | Select a passage and save a local link back to it. Reopening should find the passage or show the original page if it changed. |

Glance uses a toggle shortcut. Hold-to-preview, automatic hover previews, background preloading, and saved passage markers are not implemented.
