# Security

Please [report vulnerabilities privately](https://github.com/nuance-dev/Web/security/advisories/new). Include the affected version, steps to reproduce, and the impact. Avoid sharing credentials or personal browsing data.

Web is a development preview. Security fixes target the latest source on `main`; older builds are not maintained. There is no guaranteed response time.

The [security review](docs/security-audit.md) records current protections and known limits. It is not an independent audit.
